# Install VOG World on Windows
Download VOG-World-Windows-x64 from a successful build's Artifacts section. Extract the download and any inner ZIP.

Copy the complete VOG World.vst3 folder to:
C:\Program Files\Common Files\VST3

Restart/rescan your DAW. Load VOG World on a MIDI/instrument track. Click a pad and play the keyboard, or press PLAY / ARM PADS. For DAW-synced autoplay, also start the host transport.

Standalone: run VOG World.exe and choose audio/MIDI devices in its audio settings. The factory sounds need no samples. Optional sample recording/loading and save tools are described in README.md.

Uninstall: close your DAW and remove the installed .vst3 folder. Keep your .vworld, .wpad and WAV files if needed.
